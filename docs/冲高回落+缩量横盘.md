你提到的“**最近60个交易日冲高回落，然后缩量横盘**”，实际上是一个**小型主力路径**，恰好可以和上一回合讲的大周期框架（吸筹→拉升/锁仓→洗盘→抛售）形成呼应——大周期看"底峰锁定"，中小周期则盯"冲高回落+缩量横盘"的共振机会。

## 一、先复盘形态背后的主力逻辑

从主力操盘角度看，这种结构的实质是：**完成一轮快速拉升后，主力通过缩量横盘洗清浮筹，同时不让筹码大量上移跑掉（即"底峰锁定"的微观表现）。**

用你的筛选条件画一个时间轴：

```
┌─────────────┬─────────────┬─────────────┐
│  吸筹期     │  冲高/试盘  │  缩量横盘   │
│ （含锁仓）  │  （60日内） │ （当前阶段） │
└─────────────┴─────────────┴─────────────┘
```

- **冲高回落**（60日内发生）：通常是主力拉高测试上方抛压和跟风意愿，试盘性质。
- **缩量横盘**（当前阶段）：如果股价高位放量横盘，是"主力悄悄派发筹码的危险信号"；而**成交量的极度萎缩，恰恰证明大部分筹码被主力资金牢牢锁定，市场抛压极小**，这才是积极信号。
- **连续缩量**说明场内抛压全来自散户，主力筹码全程锁定。
- **配合筹码峰**：如果底部筹码峰在此期间基本不动——从横盘前到横盘后，底部峰的比例变化很小——意味着主力没有在横盘中逢高减仓，这是判断"真锁仓vs假横盘"的核心抓手。

## 二、细化筛选条件：把"冲高回落+缩量横盘"量化

要把这个形态变成可执行的筛选，需要拆成**五个维度**，下面给出可直接套用的**量化参数标准**（数值均可手动调节）：

| 筛选维度 | 量化具体条件 | 参数说明 |
| :--- | :--- | :--- |
| **① 横盘识别** | 最近N2天内，股价波动幅度 ≤ 某阈值（如≤15%），表明处于横盘整理 | N2建议15~25天，阈值可设10%~15% |
| **② 缩量确认** | 近5~10天的成交量连续低于20日均量线的特定倍数（如0.6倍、0.7倍）**且呈递减趋势** | 常用0.5~0.7倍，倍数越小，缩量越极致 |
| **③ 冲高识别** | 在近60个交易日内出现过一波高点，股价从最高点回落幅度 ≥ 15%~20%（表明冲高后有效回落） | 可用HHV获取60日内高点，对比当前收盘价 |
| **④ 无放量异动** | 缩量横盘期间未出现单日成交量异常放大（如放大至20日成交量均值的2.0倍或以上） | 排除"横盘后放量滞涨"和假突破诱多 |
| **⑤ 剔除范围** | 剔除ST股票、上市不足60日的新股，避免新股流动性不可比 | 可选，提高筛选质量和稳定性 |

两个较成熟的横盘描述公式供参考：
- **波动收窄**：`REF(((HHV(H,N)-LLV(L,N))/LLV(L,N)),1) <= (n1/100)`（N为横盘天数，n1为上下浮动百分比）。
- **量坑公式**：`VOL < MA(VOL,20) * 0.7`，作为缩量的基本确认逻辑。

> **实操建议**：以上条件可以逐个填入你的交易软件（通达信/同花顺/东方财富等）"条件选股"模块。每个券商软件入口位置略有差异，一般在"选股器"或"智能选股"中可找到"条件选股"功能，逐项设置即可自动扫描全市场。

## 三、用两个通达信公式"落地跑"

下面提供两个比较实用的主线公式，可直接粘贴到通达信公式管理器（`Ctrl+F` → 新建 → 粘贴 → 保存，再通过"条件选股"运行）。

### ① 波段回落选股法（适合"冲高回落＋缩量横盘"主线）

```text
{波段回落选股公式}
{用法：判断股票是否处于波段回落后的低位整理期}
{参数调节：N(1-100)参数可根据自己经验调节}
N:=60;      {60日阶段高点周期}
N1:=20;     {近期振幅统计周期}
N2:=10;     {近期缩量统计周期}
{近60日内找到最高价HHV_H}
HHV_H:=HHV(H,N);
{从高点回落的幅度}
回落幅度:=(HHV_H-CLOSE)/HHV_H*100;
{近期振幅较小，表明横盘}
横盘条件:= (HHV(H,N1)-LLV(L,N1))/LLV(L,N1)*100 <= 15;
{近期成交量持续缩量——对比20日均量}
缩量条件:= MA(VOL,N2) < MA(VOL,20)*0.7;
{满足条件选股}
选股: 回落幅度>15 AND 横盘条件 AND 缩量条件;
```

以上条件可复制粘贴到通达信公式管理器中。**参数调校建议**：
- `回落幅度>15`：表示从60日高点跌了15%以上（避免还在冲高途中就筛选出来），如果是温和试盘—洗盘，此值可适当收窄到10%。
- `横盘条件≤15%`：表示20个交易日股价在最高与最低间波动不超过15%，且**振幅持续缩小**（不出现单日放量长阳），才是真正横盘。
- `缩量条件<0.7倍`：**越往下压（如设为0.5甚至0.4），选出的票越少，但信号纯度越高**。

### ② 主力锁仓监控选股（筹码锁定的缩量横盘）

把筹码概念也融入进去，配合上回合的"底峰锁定"逻辑：

```text
{主力锁仓监控选股}
{底仓锁定识别：在横盘期间下方筹码不松动}
HJ:=5;      {价托周期}
横盘天数:=20;
横盘振幅:= (HHV(H,横盘天数)-LLV(L,横盘天数))/LLV(L,横盘天数)<=0.12;
{当前缩量程度}
量缩价稳:= MA(VOL,5) < REF(MA(VOL,5),横盘天数)*0.5;
{筹码不松动：底部20%价格区域内筹码占比锁定}
V10:=WINNER(CLOSE*0.85);
V20:=WINNER(CLOSE*0.92);
底部锁仓:= (V20-V10) < 0.1;
选股: 横盘振幅 AND 量缩价稳 AND 底部锁仓;
```

**参数调校建议**：
- `0.85` 和 `0.92` 对应"当前股价的85%~92%"价格带（即底部区域），更适合习惯观察"主峰下方"的投资者。
- 如果在软件中能准确提取**60日均价/某箱底平台到收盘价**的范围来界定底部区域，效果会更稳定。

**一句话记住操作感受：**
> **"没缩量—不关心；见了缩量横盘—上量价+筹码，看底峰动不动。"**

## 四、真假横盘的辨别

搜到的资料提醒了两个非常容易被误判的陷阱：

1. **缩量横盘≠仅仅是放量**：如果"最近60日冲高回落，缩量横盘"中**突然出现一根放量阴线或连续几根放量中阴**，且底部筹码峰明显松动（锁不住），应警惕为主力换手出货。
2. **横盘区间不应持续破位**：缩量横盘中若出现**连续两个交易日收盘价跌破横盘箱体下沿**，且成交量放大，则不再是洗盘信号，可能转为抛售或趋势逆转的开始。
3. **确认起爆点的前置信号**：横盘末期，若出现一根放量阳线突破横盘高点，则视为启动信号；突破前不应重仓参与。
4. **关注量价关系变化**：横盘期间**成交量持续萎缩，每日涨跌幅不大，K线多为小阴小阳**，市场等待新的方向或积聚能量准备展开下一波行情。
