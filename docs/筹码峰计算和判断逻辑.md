
筹码峰本质上是一张"持仓成本地图"，它能告诉你**其他人在哪个价位买了多少，尤其是主力大资金在做什么**。主力可以操纵K线和成交量，但他藏不住自己在哪个价位屯了大量"兵"（筹码）。

---

## 筹码峰计算逻辑

筹码分布是估算模型，**没有单一的筹码峰计算公式**，而是由一系列环环相扣的公式构成。核心是从**成本分布函数**出发，经过**衰减修正→分布处理→集中度量化**，最终生成右视图上那座红蓝相间的"山峰"。

### 一、同花顺筹码峰是如何计算的？

筹码峰是一种通过数学模型估算出来的数据，并非绝对精确的同花顺内部黑匣子算法，但关键在于**历史换手衰减系数**的设置。

这个系数排除了十大流通股东（如大股东、国家队）通常不动的那部分筹码，只看真正在市场中流动的股票。计算公式为：**历史换手衰减系数 = 1 / (1 - 前十大流通股东累计持股比例)**。

默认值为1，如果前十大股东持股比例很高（如80%），需要将此系数设为5甚至更高，才能看到剔除大股东后真实有效的筹码分布。

---

### 二、核心图形概念

同花顺的筹码分布图通常包含以下元素：

*   **山峰形态**：简称"峰"，可以直观看到筹码集中的位置：
    *   **单峰密集**：筹码集中在狭窄的价格区间，形成一座"山峰"，代表市场持仓成本高度一致，是变盘的前兆。
    *   **多峰密集**：筹码分布在多个价格区间，形成两个或以上"山峰"，代表市场存在成本分层，分歧较大。
    *   **发散形态**：筹码从密集区向两端扩散，代表趋势正在快速推进或崩溃。
*   **颜色与线型**（同花顺常规定义，具体以软件为准）：
    *   **红色/暖色筹码**：通常代表"获利盘"。
    *   **蓝色/冷色筹码**：通常代表"套牢盘"。
    *   **白色/黄色线**：代表市场平均成本，是所有持仓者的平均买入价。

### 三、起点：CM(参数列表)

同花顺筹码峰的核心底层函数是 **CM(参数列表)**，各参数含义如下：

| 参数位置 | 含义 | 可选值 |
|---|---|---|
| 第1个 | 计算总天数 | 0=全部天数 |
| 第2个 | 当日成本算法 | 0=平均分布，1=三角分布 |
| 第3个 | 精度 | 通常为2 |
| 第4个 | 起始位置 | 0=当天，1=前一天 |
| 第6个 | 计算方式 | 1=按成交量，2=按成交金额 |
| **第10个** | **历史换手衰减系数** | 默认1，可取0.1~10 |

### 四、修正：历史换手衰减系数（最关键）

筹码图上显示的并非"所有人"的持仓，而是**剔除了长期持股的"死筹"**后，市场上真正在交易的筹码。因此需要先计算该系数：

**公式一（简洁版）**：
```
历史换手衰减系数 = 1 / (1 - 前十大流通股东累计持股比例)
```

**公式二（精确版）**：
```
权重 = 衰减因子^(N - 1)
```
其中N表示距离当前的天数，衰减因子可手动设0.9~0.99。越接近1，历史数据权重越大。

**公式三（同花顺公式函数版）**：
```
换手率1 = VOL / 总股本 × 100%
换手率2 = VOL / 自由流通股本 × 100%
衰减系数 = 换手率2 / 换手率1
```

对照速查表：
- 前十大持股占比 **5%** → 系数 **1.05**
- **80%** → 系数 **5.00**
- **90%** → 系数 **10.00**

---

### 五、每日股票持筹分配（核心推演公式）

拿到衰减系数后，每日成本分布按此公式推算：
```
当日成本分布 = 当日成本 × (换手率 × 衰减系数) + 上一日分布 × (1 - 换手率 × 衰减系数)
```
这是一个**移动加权平均**过程，每天"搬移"一部分筹码计入最新成本，其余保留原分布。

当日成本的具体分配方式有两种：
- **平均分布**：当日换手筹码在最高价与最低价间均匀平分
- **三角分布**：最高价、平均价、最低价之间按"少两端、多中间"的形态分配

同花顺默认使用**平均分布**。

---

### 六、成本集中度（全部计算公式汇总）

**70%与90%成本集中度**：
```
集中度 = (区间上限 - 区间下限) / (区间上限 + 区间下限)
```

**区间重合度**：
```
重合度 = (70%上限 - 70%下限) / (90%上限 - 90%下限)
```
重合度越接近1，筹码越集中在中间区间。

**另一种集中度算法（自由资金模式）**：
```
集中度 = (前90%投资者的资金总额) / (所有投资者的资金总额)
```

**选股用的集中度判断（通达信版，同花顺通用）**：
```
集中度 = COST(95) - COST(5)   // 两头各去掉5%
区间   = COST(95)
选股条件 = 集中度 / 区间 × 100 < 10   // 集中度小于10%
```

**自定义筹码集中度：
```
集中度 = (COST(95) - COST(5)) / (COST(95) + COST(5)) × 100
```

## 筹码峰指标使用


### 一、如何通过筹码峰判断主力行为？

通过观察筹码峰的"移动轨迹"和"形态变化"，可以对主力行为进行判断。

#### 1. 建仓与吸筹

*   **价位特征**：个股在经历前期下跌后，于长期底部区域（如近一年30%分位以下）横盘震荡。
*   **筹码形态**：高位沉重的"蓝色套牢盘"逐渐消失、变薄，而一个厚厚的"红色获利盘"山峰在底部区间形成并不断增高。
*   **关键指标**：90%成本集中度数值降至**10%-15%以下**，且持续10天以上【19†L10-L11, L19-L20】。
*   **成交量配合**：成交量呈现**温和放大**（比之前高30%-50%），但不会突然放大到均量的2倍以上，这是主力小心翼翼吸纳筹码的痕迹。

#### 2. 洗盘

*   **价位特征**：主力完成吸筹后，股价开始初步拉升，随后主动打压股价。
*   **筹码形态①**：主力在拉升初期，制造剧烈的上下震荡，筹码图呈现出"双峰"形态，**关键看底部的筹码峰是否依然稳固**。
*   **筹码形态②**：股价短期下跌，但下方底部筹码峰**纹丝不动，并未显著减少**。
*   **关键指标**：洗盘时成交量通常会**持续萎缩**，甚至缩至近期均量的1/2以下。
*   **核心要义**：洗盘不卖。

#### 3. 锁仓

*   **价位特征**：个股正处于上涨趋势中，股价脱离底部成本区，但主力的筹码并未跟随股价上涨而向上转移。
*   **筹码形态**：**"底峰锁定，行情未尽"**。股价上涨的同时，底部的"红色筹码峰"依然存在且高度稳定。
*   **关键指标**：筹码集中度高，但成交量反而出现**萎缩**，说明主力牢牢控制局面，并未进行大规模对倒或派发。
*   **核心要义**：锁仓不卖。

#### 4. 拉升中继

*   **价位特征**：处于上涨趋势中途。
*   **筹码形态**：筹码出现"多峰"排列，底部筹码峰依然稳固，同时在上方形成新的密集峰。
*   **成交量配合**：上涨放量、回调缩量，总体量能保持健康。

#### 5. 抛售

*   **价位特征**：股价处于长期上涨后的高位，股价上涨乏力。
*   **筹码形态**：**最危险的信号是高位单峰密集**，筹码堆积在高位，且底部的获利筹码峰**快速消失、大幅变薄**，甚至完全消失。筹码图呈现"散沙状"或多峰散乱，无主峰。
*   **关键指标①**：在股价拉升末期，收盘获利比例连续处于**90%以上**高位，随后筹码集中度突然增大。
*   **关键指标②**：高位出现天量阴线或十字星，成交量巨大但股价滞涨或下跌。
*   **核心要义**：抛售不恋。

---


### 二、关键指标详解

在筹码分布图的右侧或上方，通常会看到以下关键数据：

*   **收盘获利（获利盘比例）**：
    *   **高于80%**：需警惕回调风险。
    *   **低于30%**：可能有反弹机会。
    *   **90%-100%**：高度警惕，可能是主力拉高出货的信号。
*   **平均成本**：市场成本重心。现价在之上易形成支撑，之下则抛压较重。
*   **90%/70%成本区间与集中度**：
    *   **集中度计算公式**：(上限 - 下限) / (上限 + 下限)。
    *   **集中度越低**，筹码越集中（小于**10%** 视为高度集中），主力控盘可能性越高。
*   **区间重合度**：指70%筹码区间占90%筹码区间的比例，重合度越高，筹码越集中。

---

### 三、注意事项

*   **不可独立使用**：筹码峰分析必须与成交量、K线形态、大盘环境和公司基本面结合使用，单一指标容易产生误判。
*   **警惕假信号**：主力有时会通过对倒交易制造虚假筹码信号，需通过量能、盘口综合验证。
*   **券商差异**：不同券商软件的筹码峰算法可能存在细微差异，建议以个股历史的筹码变化趋势为主要参考。
